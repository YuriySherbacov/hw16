# Homework — AWS EC2, S3 та IAM

## Опис
Практична робота з базовими сервісами AWS:
- створення та видалення тестового EC2
- робота з S3 bucket
- створення IAM policy і тестового користувача з обмеженим доступом

## Завдання 1. EC2
- Створено EC2 типу `t2.micro` на Ubuntu з публічною IP
- Виконано підключення по SSH
- Інстанс видалено (Terminate)

## Завдання 2. S3 + IAM
- Створено бакет `yurii-test-bucket-123456`
- Завантажено тестовий файл і скачано його на ПК
- Створено IAM policy `OnlyMyTestBucketPolicy` з доступом лише до цього бакета
- Створено IAM user `test-s3-user` і призначено йому цю політику
- Перевірено вхід під тестовим користувачем
- Перевірено, що доступ до інших S3 бакетів заборонений
- Видалено тестового користувача, політику та створений бакет

## Скріни
Усі скріни виконання додані відповідно до формату здачі.

## Важливо
Інші існуючі S3 бакети не видалялись.
